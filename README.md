# Call Center Performance & SLA Dashboard (Power BI)

An interactive **Power BI** dashboard analyzing call center volume, abandonment rate, threshold rate, average speed of answer (ASA), handled vs. abandoned calls, and agent/project performance across months and projects (`Project A`, `Project B`, `Project C`).

## 📌 Dashboard Sections & Key Features

### 1. Call Analysis Overview (`CALL ANALYSIS`)
- **KPIs:** Total Calls (`1.74M`), Abandon Rate (`1.32%`), and Threshold Rate (`91.06%`).
- **Visuals:** Success rate vs. abandon rate donut chart, average ASA by month, monthly success rate trend, and abandon rate vs. calls offered by month.

### 2. Project, Monthly & Agent Breakdown
- **KPIs:** `ASA`, `Handled Calls`, and `Abandon Calls` (e.g., `444.1K` handled calls and `5.78` ASA in February vs. `188.2K` handled calls and `6.82` ASA in April).
- **Visuals:** Handling rate vs. abandon rate by project, handling rate vs. threshold rate by project, and handling rate vs. threshold rate by agent.

### 3. Navigation, Slicers & Tooltip
- **Interactive Controls:** `Project` and `Month` slicers, left navigation panel, and a dedicated report tooltip page.
